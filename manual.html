五次元囲碁ビューア 操作マニュアル

立体囲碁操作マニュアル（黄色ボタン）

1. 「人間対人間」ボタンを押し、入力層を選び、格子の交点を選んで左クリックすると、黒石、白石を交互に置け　 　　るよ。又入力盤に石を置くと、即立体盤に描写されるよ。

2. 「１」で入力された石は、立体盤の中で、相手の石を前後、左右、上下、で囲むと、相手の石が取れるよ。

3. 入力盤の一層目は立体盤の最下部に該当し、二層目、三層目と一層づつ対応しているよ。

4. 入力は立体盤の該当層が黄色になるよ。一層目の黄色い四角を立体盤二次元盤の目印にしてね。

5. 「人間対人間」で戦った後「人間対AI」で戦ってみよう。AIは強いAIボタンがあるよ。 6. 三次元盤をクリックしてコロコロを使うと拡大縮小ができるよ。右クリックで移動、左クリックで回転だよ。

三次元囲碁研究マニュアル（青ボタン）

1. 「三次元囲碁デモ」を押すと最も基本的な石取のパターンが見えます戦いの参考にしてね。

2. 「AI 対 AI」ボタンを押すと、AI 同士の対戦が始まります。参考にしてね。

多次元囲碁動画（赤ボタン）

1. 2次元囲碁は２台のpcの通信系の囲碁ゲームだよ、石をとると、背後の宇宙服のアイテムが回転するよ。

2. 3次元囲碁はWebのゲームと同じだよ。入力盤webのはように黄色いボタンでコントロールしていませんが、立体の下に立体盤の５層に対応して５枚並んで入力できるようになっているよ。

3. 4次元囲碁は 3次元囲碁に「時間軸」が加わったものです。
　・左側の 上から三番目の立体盤が時間 = 0（現在）
　・その上の層が時間 = 1（+1秒後）
　・さらに上が時間 = 2（+2秒後）
　・逆に下の層が時間 = -1（1秒前）

　・さらに下の層が時間 = -2（2秒前）

時間=0で前後左右上下を囲んでも石をとれないよ、時間=‐1,1の両方の同じ場所をい方の石で塞がないと相手の石は取れないよ。 4. 5次元囲碁は三次元囲碁の位置を表す変数(x,y,z)のzに二次元囲碁の変数(t,u)尾ぶら下げて作ったよ、石をとるには、四次元囲碁の８方向(前後左右上下、一葉目一秒後)の八方向＋２方向 　　からの閉鎖が必要だよ、なかなかわからないけど、赤い石を置いたときの盤の様子を観察してね。
